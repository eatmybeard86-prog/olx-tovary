# Пошук товарів OLX

Веб-додаток для пошуку оголошень OLX.ua: електроніка, комп'ютери, телевізори, побутова техніка, транспорт, запчастини, шини/диски/колеса, меблі.

- **Нові оголошення щогодини.** Збирач (GitHub Actions) запускається кожну годину і додає нові оголошення.
- **Неактивні зникають.** Збирач перевіряє відомі оголошення на OLX; зняті з продажу ховаються (їх можна показати галочкою «показати зняті»).
- **Динаміка цін.** Кожна зміна ціни записується: у картці оголошення є графік і таблиця змін, у списку — позначки «↓ 10%», а вкладка «Динаміка цін» показує медіанну ціну, нові/зняті оголошення за день і розподіл цін — для поточних фільтрів і зони.
- **Детальний фільтр залежно від категорії.** Фільтри будуються з параметрів самих оголошень OLX (діагональ, марка, рік, пробіг, оперативна пам'ять, розмір шин тощо), плюс ціна, підкатегорія, дата, «ціна знижувалась», приватна особа/бізнес.
- **Зона пошуку на карті будь-якого розміру.** На вкладці «Карта» малюєте прямокутник, коло або довільний багатокутник; зон може бути кілька. Зберігаються у браузері.
- Працює з телефону, без встановлення. Сайт — GitHub Pages (безкоштовно), сервер не потрібен.

## Як це влаштовано

```
config.json              ← що і де збирати (категорії, зона збору)
scraper/olx_scraper.py   ← збирач (Python, без залежностей)
index.html, app.js, style.css ← сайт
.github/workflows/update.yml  ← щогодинний запуск: збір → гілка data → публікація сайту
```

Дані зберігаються в окремій гілці `data` (перезаписується щоразу, без історії, щоб репозиторій не роздувався).

## Запуск (≈5 хвилин)

1. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
2. Переконайтесь, що робоча гілка з кодом — гілка за замовчуванням (Settings → General → Default branch), бо GitHub запускає розклад лише з неї.
3. **Actions → «Оновлення оголошень» → Run workflow** — перший запуск вручну. Далі — автоматично щогодини.
4. Адреса сайту з'явиться в підсумку запуску і в Settings → Pages (вигляду `https://<логін>.github.io/olx-tovary/`).

## Налаштування (`config.json`)

- `area` — зона збору. Коло: `"type": "circle", "lat", "lon", "radius_km"`. Можна прямокутник (`"type": "bbox", "south", "north", "west", "east"`) або вся Україна (`"type": "all"`, дуже багато даних — не радимо). Свою зону пошуку будь-якого розміру малюєте вже на сайті, всередині зони збору.
- `categories` — категорії сайту і шляхи OLX (як в адресі сторінки OLX, напр. `elektronika/tv-videotehnika`). Номери категорій визначаються автоматично; якщо не вийде, на сайті з'явиться попередження — тоді допишіть `"ids": [номер]`.
- `region_ids` — області OLX; порожньо = визначаються самі після першого запуску.
- `check_budget_per_run` — скільки відомих оголошень перевіряти за один запуск (на зникнення та зміну ціни).

## Запуск на своєму комп'ютері (необов'язково)

```bash
python scraper/olx_scraper.py --config config.json --data data
python -m http.server 8000   # і відкрити http://localhost:8000
```

Тести: `python -m unittest discover -s scraper`

## Обмеження

- Координати в OLX приблизні (продавець часто вказує лише місто чи район), тому дуже мала зона на карті може відсікати потрібні оголошення.
- OLX може тимчасово обмежувати часті запити; тоді частина перевірок переноситься на наступну годину (на сайті буде попередження).
- GitHub вимикає розклад, якщо в репозиторії 60 днів не було змін — тоді достатньо натиснути «Enable workflow» в Actions.
